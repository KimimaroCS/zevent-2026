Pubs sur iPad / navigateur

Être connectée dans l’app Twitch ne compte pas ici. Safari (et Chrome sur iPad) bloque les cookies des lecteurs embarqués : sans session Twitch dans ce navigateur, Turbo / abo / Prime ne s’appliquent pas → pubs.

Discord Nitro n’enlève pas les pubs Twitch. Il faut Twitch Turbo, un abo chaîne, ou Prime Gaming sur le compte avec lequel tu te connectes.

  1. iPad → Réglages → Safari (ou Réglages → Apps → Safari) → désactiver Empêcher le suivi intersite.
  2. Ouvre twitch.tv, connecte-toi avec le compte Turbo / abo / Prime.
  3. Reviens ici et appuie sur Recharger les lives.
  4. Si les pubs restent : dans un live, appuie sur Twitch pour l’ouvrir en plein site / dans l’app — là, plus de pubs.
