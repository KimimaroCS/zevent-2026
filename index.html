Compte Twitch & pubs

Ce site n’est pas Twitch : les lives sont des lecteurs embarqués. Un bouton « Se connecter » sur la page ne suffit pas — le navigateur isole les cookies.

Pour profiter de Twitch Turbo, d’un abonnement à la chaîne ou de Prime Gaming (ce n’est pas Discord Nitro), connecte-toi dans le player Twitch ci-dessous, via l’icône compte.

  1. Clique l’icône compte dans le player, puis connecte-toi.
  2. Si rien ne change, ouvre aussi la page de connexion Twitch (popup).
  3. Recharge ensuite les lives pour appliquer la session à toute la grille.
